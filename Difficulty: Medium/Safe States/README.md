<h2><a href="https://www.geeksforgeeks.org/problems/eventual-safe-states/1">Safe States</a></h2><h3>Difficulty Level : Difficulty: Medium</h3><hr><div class="problems_problem_content__Xm_eO" style="--text-color: var(--problem-text-color);"><p class="MsoNormal"><span style="font-size: 18.6667px;">Given a directed graph with <strong>V</strong> vertices numbered from 0 to V-1 and <strong>E</strong> directed edges, represented as a 2D array <strong>edges[][]</strong>, where edges[i] = [u, v] represents a directed edge from vertex u to vertex v.</span></p>
<p class="MsoNormal"><span style="font-size: 18.6667px;">A vertex with no outgoing edges is called a terminal node. A vertex is considered safe if every possible path starting from that vertex eventually reaches a terminal node.</span></p>
<p class="MsoNormal"><span style="font-size: 18.6667px;">Return all the safe nodes of the graph.</span></p>
<p><span style="font-size: 14pt;"><strong>Examples:&nbsp;</strong></span></p>
<pre><span style="font-size: 14pt;"><strong>Input: </strong>V = 5, E = 6, edges[][] = [[1, 0], [1, 2], [1, 3], [1, 4], [2, 3], [3, 4]]<strong><br><img src="https://media.geeksforgeeks.org/img-practice/prod/addEditProblem/913663/Web/Other/blobid0_1761648473.webp" width="268" height="169"></strong></span><br><span style="font-size: 14pt;"><strong>Output: </strong>[0, 1, 2, 3, 4]
<strong>Explanation: </strong></span><span style="font-size: 18.6667px;">Nodes 0 and 4 have no outgoing edges, so they are terminal nodes. All paths starting from nodes 1, 2, and 3 eventually reach terminal node 4. Therefore, all nodes are safe.</span></pre>
<pre><span style="font-size: 14pt;"><strong>Input: </strong>V = 4, E = 3, edges[][] = [[1, 2], [2, 3], [3, 2]]<strong><br><img src="https://media.geeksforgeeks.org/img-practice/prod/addEditProblem/913663/Web/Other/blobid1_1761648488.webp" width="277" height="149"></strong></span><br><span style="font-size: 14pt;"><strong>Output: </strong>[0]
<strong>Explanation: </strong></span><span style="font-size: 18.6667px;">Node 0 is a terminal node. Nodes 2 and 3 form a cycle, so they are not safe. Node 1 leads to the cycle, making it unsafe. Hence, only node 0 is a safe node.</span></pre>
