<h2><a href="https://www.geeksforgeeks.org/problems/number-of-islands/1">Number of Islands After K Operations</a></h2><h3>Difficulty Level : Difficulty: Medium</h3><hr><div class="problems_problem_content__Xm_eO" style="--text-color: var(--problem-text-color);"><p><span style="font-size: 18.6667px;">Given a grid of <strong>n</strong> rows and<strong> m</strong> columns. Initially, all cells of the grid contain 0, where 0 represents water. </span><span style="font-size: 18.6667px;">You are also given a 2D array <strong>operators[][]</strong>, where each operator<strong>&nbsp;</strong>contains two integers representing the row and column of a cell. Each operation converts the specified water cell into land by changing its value from 0 to 1.</span></p>
<p><span style="font-size: 18.6667px;">After each operation, find the number of islands present in the grid.</span></p>
<p><span style="font-size: 18.6667px;">An island is a group of one or more land cells (or 1s) that are connected through their top, bottom, left, or right sides. Cells connected only diagonally are not considered part of the same island. </span><span style="font-size: 18.6667px;">Return an array containing the number of islands after each operation.</span></p>
<p><strong><span style="font-size: 18px;">Examples:</span></strong></p>
<pre><span style="font-size: 18px;"><strong>Input:</strong> n = 4, m = 4, k = 4, <span style="font-family: -apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, Oxygen, Ubuntu, Cantarell, 'Open Sans', 'Helvetica Neue', sans-serif; font-size: 18.6667px; white-space: normal;">operators[][]</span>= [[1,1],[0,1],[3,3],[3,4]]</span>
<span style="font-size: 18px;"><strong style="font-size: 18px;">Output:</strong><span style="font-size: 18px;"> [1, 1, 2, 2]
</span><strong style="font-size: 18px;">Explanation: </strong><span style="font-size: 18px;">Initially, all cells contain 0, so there are no islands.
- After operation 1, cell (1,1) becomes land. It forms one island, so the count is 1.
- After operation 2, cell (0,1) becomes land. It is connected to the land cell at (1,1), so both cells form one island. The count remains 1.
- After operation 3, cell (3,3) becomes land. It is not connected to the existing island, so a new island is formed. The count becomes 2.
- After operation 4, cell (3,4) becomes land. It is connected to (3,3), so both cells form one island. The total count remains 2.<br></span><span style="font-size: 14pt;"><span style="font-size: 14pt;">Therefore, the number of islands after each operation is [1, 1, 2, 2].<br><br><img src="https://media.geeksforgeeks.org/img-practice/prod/addEditProblem/932886/Web/Other/blobid0_1786353136.png" alt="" width="629" height="474"></span></span><br></span></pre>
<pre><span style="font-size: 18px;"><strong>Input:</strong> n = 4, m = 5, k = 4, operators[][] = [[0,0],[1,1],[2,2],[3,3]]</span>
<span style="font-size: 18px;"><strong style="font-size: 18px;">Output:</strong><span style="font-size: 18px;"> [1, 2, 3, 4]
</span><strong style="font-size: 18px;">Explanation: </strong><span style="font-size: 18px;">Initially, all cells contain 0, so there are no islands.
- After operation 1, cell (0,0) becomes land. It forms one island, so the count is 1.
- After operation 2, cell (1,1) becomes land. It is diagonally connected to (0,0), but diagonal cells are not considered connected. Therefore, it forms a new island and the count becomes 2.
- After operation 3, cell (2,2) becomes land. It is not connected through a side to any existing island, so another island is formed. The count becomes 3.
- After operation 4, cell (3,3) becomes land. It is also not connected through a side to any existing island, so the count becomes 4.
Therefore, the number of islands after each operation <span style="font-size: 14pt;">is </span></span><span style="font-size: 14pt;">[1, 2, 3, 4].</span><span style="font-size: 18px;"><br></span><span style="font-size: 18px;">
